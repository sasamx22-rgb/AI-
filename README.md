# AI 비서 (회계 업무 자동화)

Claude Code로 구동되는 회계 업무 보조 AI 비서입니다. 사용자, 작성
담당 **에이미**(executor), 검토 담당 **제임스**(reviewer) 세 명이
하나의 대화창에서 함께 일합니다. 에이미가 초안을 쓰고, 제임스가
검토·반박·재검토를 거쳐 승인하면 최종본이 확정됩니다.

## 시작하기

```bash
npm install -g @anthropic-ai/claude-code
git clone https://github.com/sasamx22-rgb/ai-.git
cd ai-
claude
```

Claude Code를 실행하면 이 폴더의 `CLAUDE.md`를 자동으로 읽어 비서의
행동 규칙을 적용합니다.

## 사용법 (대화형, 기본값)

1. `inputs/`에 원본 자료(엑셀, PDF, 지시사항 등)를 넣습니다.
2. Claude Code 대화창에서 이름 없이 그냥 업무를 지시합니다.

   ```
   2026년 3분기 실적 보고서 워드로 만들어줘
   ```

3. **자동으로 에이미가 맡아 초안을 만들고, 이어서 제임스가 따로
   요청하지 않아도 자동으로 검토합니다.** 사용자가 매번 "에이미,
   ~" / "제임스, ~"라고 따로 부를 필요는 없습니다.
4. 제임스가 지적하면 에이미가 동의하는 부분은 반영하고, 동의하지
   않으면 근거를 들어 반박합니다 — 필요하면 여러 차례 주고받으며
   대화창에서 논의가 이어집니다. 사용자는 언제든 끼어들어 지시하거나
   판단을 내릴 수 있습니다.
5. 제임스가 명시적으로 승인하면 에이미가 그 버전을
   `outputs/<주제>-final.<확장자>`로 복사해 최종본을 만듭니다.

특정 인물에게만 따로 말을 걸고 싶을 때(예: "에이미, 왜 이렇게 썼어?",
"제임스, 이 부분만 다시 봐줘")는 언제든 이름을 불러 직접 지시할 수
있습니다.

대화 없이 빠르게 한 번에 돌리고 싶다면 `/report [요청 내용]`
커맨드로 전체 사이클(작성→검토→반박→수정 반복→최종본)을 자동 실행할
수도 있습니다.

## 채팅 앱으로 쓰기 (터미널 없이)

터미널 대신 브라우저 채팅창에서 파일 업로드 + 대화 입력만으로 쓰고
싶다면 `app/` 폴더의 로컬 웹앱을 사용하세요.

```bash
채팅앱-실행.bat   # Windows에서 더블클릭해도 됩니다
```

처음 실행하면 필요한 패키지를 자동으로 설치한 뒤 브라우저가 열리고,
`http://localhost:4000`에서 나(보스) / 🧑‍💼 에이미 / ⚖️ 제임스가
말풍선으로 구분된 채팅창이 뜹니다. 📎 버튼으로 파일을 올리면 자동으로
`inputs/`에 저장되고, 입력창에 업무를 지시하면 뒤에서 `claude` CLI가
이 프로젝트 폴더를 대상으로 실행됩니다.

**채팅창은 하나지만, 에이미와 제임스는 각각 독립된 세션입니다.**
`claude --agent executor`(에이미)와 `claude --agent reviewer`(제임스)를
각자 별도의 `--session-id`로 띄워서, 서버를 켜둔 동안 둘 다 자기
대화 전체를 스스로 기억합니다(서로의 속마음은 공유하지 않고, 서로
주고받은 말만 서로에게 전달됩니다). 채팅창 안에서 동작 방식은 이렇습니다.

- 이름 없이 그냥 지시하면(예: "3분기 보고서 워드로 만들어줘") →
  에이미가 작성 → 제임스가 자동으로 검토 → 반려면 에이미가 반영/반박
  → 다시 제임스가 재검토, 이 흐름을 승인이 나거나 반려가 3회
  반복될 때까지 자동으로 반복합니다. 승인되면 에이미가 최종본을
  만듭니다.
- "에이미, ~" / "제임스, ~"로 직접 부르면 그 세션에만 말을 걸고,
  자동 진행은 하지 않습니다.

**보안 관련 중요 사항**: 이 앱은 승인 버튼이 없는 자동화 방식이라,
`claude`를 `--permission-mode bypassPermissions`로 실행합니다 — 즉
에이미/제임스가 파일을 쓰거나 스크립트를 실행할 때마다 승인을 묻지
않고 **이 프로젝트 폴더(`AI-/`) 안에서 자동으로 실행**합니다. 이
폴더 밖의 파일은 건드리지 않지만, 폴더 안에서는 지시한 대로 즉시
실행된다는 점을 알고 사용하세요. 매 단계 승인을 받고 싶다면 앱 대신
`claude` 터미널/데스크톱 앱을 사용하세요.

## 폴더 구조

```text
CLAUDE.md               비서의 기본 행동 원칙 + 팀 대화 진행 규칙
.claude/agents/          executor(에이미, 작성) / reviewer(제임스, 검토) 정의
.claude/commands/        /report 슬래시 커맨드 (자동 실행 지름길)
app/                     터미널 없이 쓰는 브라우저 채팅앱 (선택 사항)
채팅앱-실행.bat           Windows에서 채팅앱을 실행하는 더블클릭용 파일
inputs/                  원본 자료
outputs/                 초안(v1, v2…) 및 제임스 승인 후 확정되는 최종본
                         (<주제>-final.<확장자>)
```

## 설계 원칙

- **작성자와 검토자 분리**: 문서를 만드는 주체와 승인하는 주체를
  분리해, 자기 결과물의 허점을 스스로 못 보는 문제를 줄입니다.
- **독립적인 판단 유지**: 채팅 앱에서는 에이미와 제임스가 실제로
  서로 다른 독립 세션이라(각자 `--session-id`로 자기 대화 전체를
  기억), 서로의 속마음은 전혀 공유되지 않고 명시적으로 주고받은
  말만 전달됩니다. 그래서 검토가 형식적인 동의가 아니라 실제 견제로
  작동합니다. (터미널/데스크톱 앱에서는 진행자 세션 하나가 컨텍스트를
  분리해서 같은 효과를 냅니다.)
- **규칙은 마크다운으로**: `CLAUDE.md`, `.claude/agents/*.md`를 고치는
  것만으로 비서의 행동을 바꿀 수 있습니다. 별도 코드 수정이 필요
  없습니다.
- **근거 없는 숫자 금지**: 모든 산출물의 수치는 `inputs/` 원본과
  대조 가능해야 합니다.
- **최종본은 승인 후에만**: 제임스가 명시적으로 승인하기 전까지는
  모든 버전이 초안입니다.
