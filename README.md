# AI 비서 (회계 업무 자동화)

Claude Code로 구동되는 회계 업무 보조 AI 비서입니다. 사용자, 작성
담당 **에이미**(executor), 검토 담당 **제임스**(reviewer) 세 명이
하나의 대화창에서 함께 일합니다. 에이미가 초안을 쓰고, 제임스가
검토·반박·재검토를 거쳐 승인하면 최종본이 확정됩니다.

## 시작하기

```bash
npm install -g @anthropic-ai/claude-code
git clone https://github.com/sasamx22-rgb/ai-.git
cd ai-
claude
```

Claude Code를 실행하면 이 폴더의 `CLAUDE.md`를 자동으로 읽어 비서의
행동 규칙을 적용합니다.

## 사용법 (대화형, 기본값)

1. `inputs/`에 원본 자료(엑셀, PDF, 지시사항 등)를 넣습니다.
2. Claude Code 대화창에서 직접 이름을 불러 지시합니다.

   ```
   에이미, 2026년 3분기 실적 보고서 워드로 만들어줘
   ```

3. 에이미가 초안을 만들면, 이어서 검토를 요청합니다.

   ```
   제임스, 방금 초안 검토해줘
   ```

4. 제임스가 지적하면 에이미가 동의하는 부분은 반영하고, 동의하지
   않으면 근거를 들어 반박합니다 — 필요하면 여러 차례 주고받으며
   대화창에서 논의가 이어집니다. 사용자는 언제든 끼어들어 지시하거나
   판단을 내릴 수 있습니다.
5. 제임스가 명시적으로 승인하면 에이미가 그 버전을
   `outputs/<주제>-final.<확장자>`로 복사해 최종본을 만듭니다.

대화 없이 빠르게 한 번에 돌리고 싶다면 `/report [요청 내용]`
커맨드로 전체 사이클(작성→검토→반박→수정 반복→최종본)을 자동 실행할
수도 있습니다.

## 폴더 구조

```text
CLAUDE.md               비서의 기본 행동 원칙 + 팀 대화 진행 규칙
.claude/agents/          executor(에이미, 작성) / reviewer(제임스, 검토) 정의
.claude/commands/        /report 슬래시 커맨드 (자동 실행 지름길)
inputs/                  원본 자료
outputs/                 초안(v1, v2…) 및 제임스 승인 후 확정되는 최종본
                         (<주제>-final.<확장자>)
```

## 설계 원칙

- **작성자와 검토자 분리**: 문서를 만드는 주체와 승인하는 주체를
  분리해, 자기 결과물의 허점을 스스로 못 보는 문제를 줄입니다.
- **독립적인 판단 유지**: 에이미와 제임스는 한 대화창에서 대화하듯
  일하지만, 내부 사고 과정은 서로 공유하지 않고 명시적인 발언만
  주고받습니다. 그래서 검토가 형식적인 동의가 아니라 실제 견제로
  작동합니다.
- **규칙은 마크다운으로**: `CLAUDE.md`, `.claude/agents/*.md`를 고치는
  것만으로 비서의 행동을 바꿀 수 있습니다. 별도 코드 수정이 필요
  없습니다.
- **근거 없는 숫자 금지**: 모든 산출물의 수치는 `inputs/` 원본과
  대조 가능해야 합니다.
- **최종본은 승인 후에만**: 제임스가 명시적으로 승인하기 전까지는
  모든 버전이 초안입니다.
