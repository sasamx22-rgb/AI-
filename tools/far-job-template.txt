# MAP|키|원본계정|FAR계정|부호|FAR그룹|원본순번|FAR순번|당기열|전기열        (칸 번호: 1=MAP 2=키 3=원본 4=FAR 5=부호 6=그룹 7=원본순번 8=FAR순번 9=당기열 10=전기열)
#   MAP|BS|매출채권|매출채권                          ← 이름이 같으면 FAR계정 칸은 생략해도 된다(원본 이름을 씀)
#   MAP|BS|대손충당금|대손충당금(매출채권)|-           ← 5번째 칸 부호: 원본이 양수로 보여 주는 차감계정이면 '-'
#   MAP|BS|급여|급여||판관비|2                      ← 6번째 칸 FAR그룹(소속 대항목), 7번째 칸 원본에서 같은 이름 2번째 줄
#   MAP|BS|급여|급여||판관비||2                     ← 8번째 칸 = FAR쪽에서 같은 이름 2번째 행
#   빈칸 개수에 주의: "그룹 없이 원본순번만 2" 는 MAP|BS|이름|FAR이름|||2   (|가 3개 → 5,6칸을 비우고 7칸 = 2)
# SKIP|키|원본계정|원본순번              소계처럼 입력하지 않는 원본 줄
# TIE|키|원본합계명|FAR계정|FAR그룹|당기열|전기열|원본순번|FAR순번     원본 합계와 FAR 값 대조 (자산총계·부채총계·자본총계·매출액·매출원가·영업이익·당기순이익 …)
# ADD|앞계정|새계정|공시계정|앞그룹|앞순번   양식에 없는 계정을 앞계정 아래에 추가
