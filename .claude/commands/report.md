사용자 요청: $ARGUMENTS

다음 절차를 순서대로 실행한다.

1. **작성**: `executor` 서브에이전트를 호출해 위 요청 내용에 맞는
   산출물 초안(v1)을 `outputs/`에 만들게 한다. `inputs/`의 원본 자료를
   반드시 근거로 사용하도록 지시한다.
2. **검토**: `reviewer` 서브에이전트를 호출해 방금 만든 초안을 검토
   체크리스트에 따라 확인하게 한다.
3. **분기**:
   - 문제가 없으면 → 5번으로 이동.
   - 문제가 있으면 → reviewer가 작성한 구체적 수정 지시를 `executor`에게
     전달하고, executor가 다음 버전(v2, v3…)을 만들게 한 뒤 2번으로
     돌아간다.
4. **한도**: 수정 라운드가 3회를 넘으면 자동 반복을 멈추고, 남은 쟁점과
   각 라운드에서 무엇이 바뀌었는지 요약해 사용자에게 판단을 요청한다.
5. **최종 보고**: 사용자에게 다음을 보고한다.
   - 최종 산출물 파일 경로 (`outputs/...`)
   - 몇 라운드 만에 승인되었는지
   - 라운드별로 무엇이 수정되었는지 간단한 요약
   - (있다면) reviewer가 "재확인 필요"로 표시한 항목
